# 開発用コンポーネント一覧

`/dev/components` は `NODE_ENV=development` のときだけ利用可能です。

- プレビューは製品のコンポーネントを直接 import します。複製した JSX / CSS で製品部品を再現しないでください。
- 共通コンポーネントと globals.css の変更は、同じ実装を参照するプレビューにも反映されます。
- 台帳・使用箇所・色定義は `read-catalog.ts` がリクエストごとに現在のソースから取得します。ソース変更後はページを再読み込みして最新の台帳を確認できます。
- 台帳は src/components と src/features の名前付き関数・関数式・アロー関数（大文字で始まる名前）を調べます。使用箇所は同一ファイルまたは直接 import した JSX の静的解析です。barrel 経由、動的参照、HOC は対象外です。これらを採用するときは解析も拡張してください。
- 部品を追加したら必要な props を渡す安全なプレビューも追加してください。API・認証・localStorage に依存する画面全体をカタログ上で実行しないでください。
- 統一候補は調査時点の提案で、自動更新される台帳・色一覧とは別です。置き換え時は提案も更新してください。
- 一覧用 CSS はレイアウトに限定し、プレビューの部品の色・サイズを上書きしないでください。
