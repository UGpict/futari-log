# 対応エリア（東京都内）

全国収集はしない。東京都内で、希望に合う実在スポットから移動の無理ない行程を作る。

## 範囲

- 対応: 東京都内（本土の区市町村。島嶼は座標で都外扱いし、確認する）。
- 優先エリア（拒否条件ではない）: 東京駅・丸の内、上野、浅草、渋谷・原宿、新宿、池袋、お台場。
- 都外の集合・解散・固定予定は、入力を東京へ置き換えず確認質問にする。
- 所在地が判定できないときも確認する。

## 検索

集合を中心に、近い範囲から希望カテゴリだけを探す。希望が足りないときだけ設定どおり広げる。
毎回14種全検索はしない。同一 Place ID は重ねない。
広げても足りなければ条件変更を確認する。検証は緩めない。

## 多様性

通常は同じ表示種別が続きすぎないように選ぶ。カフェ巡りなど同種連続の明示希望は尊重する。
多様性より希望・予算・営業・移動を優先する。

## 事前収集

既存のイベント ingest を優先エリアに対して呼べるようにする。全国一括はしない。
写真名は保存しない。LIVE 成功を固定候補だけで作らない。

実装の正: `src/contracts/serviceArea.ts` と `SEARCH_EXPAND`。
