# スポット種別（14）

画面のアイコン分類を、候補検索・希望マッチ・カード表示の共通基準にする。
表示用の14種別と、具体的な希望の達成判定は別物である。

| id | 表示 | 例 | スカウト桶 |

| cafe | カフェ | カフェ・喫茶・コーヒー | sweets |

| shopping | 買い物 | ショッピング・雑貨・商業施設 | other |
| cinema | 映画・舞台 | 映画館・劇場・演劇 | other |

実装の正は `src/contracts/spotKinds.ts`。

## 表示と希望

- アイコンは排他の代表種別1つ。`classifySpotKind`。
- 検索は Places の全 types（取れる範囲の `primaryType` を含む）の重なり。代表アイコンの優先順位だけでは候補から外さない。
- 希望達成は表示種別一致では足りない。希望テキストから具体ファセットを取り、その `fulfillTypes` が types にあるときだけ達成とする。
- 候補検索で取れたこと自体は、希望を満たす証拠にしない。
- 名前キーワードだけの分類は推定。MUST 達成に数えない。
- `food` だけでは食事にしない。存在しない Places type は作らない。
- ものづくり体験は確認質問のまま。

具体ファセットの例:

| 表示 | 希望 | 達成に使う type | 検索 type |
| --- | --- | --- | --- |
| 映画・舞台 | 映画 | `movie_theater` | 同左 |
| 映画・舞台 | 舞台・劇場 | `performing_arts_theater` | 同左 |
| 散策 | 公園 | `park` など | 同左 |
| 散策 | 海 | `beach` | 同左 |
| 買い物 | ショッピング | `shopping_mall` など | 同左 |
| 買い物 | 本屋 | `book_store` | 同左 |
| 遊び・体験 | 遊園地 | `amusement_park` | 同左 |
| 遊び・体験 | 動物園 | `zoo` | 同左 |
| 遊び・体験 | ものづくり | なし | なし |
| 温泉・スパ | スパ | `spa` | 同左 |
| 温泉・スパ | 温泉 | なし（Places に温泉 type が無い） | 検索前に確認。スパへの変更は回答後 |
| 食事 | 食事 | `restaurant` 系 | 同左 |
| カフェ | カフェ | `cafe` 系 | 同左 |

`cafe` と `restaurant` を両方持つ店は、カフェのアイコンでも食事候補から消さない。`cafe` だけでは食事の希望を達成しない。

「甘いもの」は cafe または sweets の type があれば達成（既存 MUST）。スイーツ単独チップは sweets のみ。

## 根拠

達成した希望は、既存の `matchesPreferenceIds` と行程の `reason` に、使った Places type を書いて残す。
表示種別が一致しただけの判定と、具体希望の type 一致を混同しない。
根拠不足は達成に数えない。MUST 未充足は ERROR のまま。

## やらない

SpotDto に種別やファセットを足して保存する、写真・再提案の変更、scout 桶を 14 に増やす。
